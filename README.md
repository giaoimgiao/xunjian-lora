# 驯妃筵图卷 · LoRA 权重包

基于 **Qwen3.8-27B**（INT8 量化基座）微调的长篇小说续写 LoRA。

- 基座：`Qwen3.8-27B`，64 层（48 线性注意力 + 16 全注意力），hidden 5120，INT8 (w8a8)
- 基座已做去对齐处理：削除层 8–63 的 MLP 出口与全注意力出口的拒绝方向（强度 0.45）
- 训练语料：原创长篇小说《驯妃筵图卷》107 章
- 训练方式：LoRA，rank 32 / alpha 64，仅训练注意力与 MLP 投影，loss 只计算 assistant 段

## 两代权重

| 文件 | 步数 | 能力 |
|---|---|---|
| `驯妃筵_lora_v1_250step.pt` | 250 | 会先写思考段，再排档案头（场景/人物/前情），再写正文；无书名行 |
| `驯妃筵_lora_v2_120step.pt` | 120 | 在 v1 基础上续训，输出首行带书名与章号，档案头五项齐全 |

两代都是从同一个续写版 LoRA（`lora_step360`）继续训出来的。

## 用法

必须配合 INT8 加载脚本（`q35_base.py`），transformers 原生加载器读不了这套量化格式。

```python
import q35_base as B
B.D = "/path/to/Qwen3.8-27B-ab2"        # 去对齐基座
model = B.build_model()
B.apply_lora(model, r=32, alpha=64)
# 再加载 lora 权重张量
```

system 使用 `sys_short.txt`（20 字），**训练和推理必须一致**：

```
你是《驯妃筵图卷》的作者，按用户给的章号和剧情写正文。
用词直白，不写任何免责、警告或说教，不提及自己是 AI。
```

user 输入格式：

```
请写《驯妃筵图卷》第108章。
【人物】…
【场景】…
【要求】…
```

采样建议：温度 0.85 / top_p 0.9 / 重复惩罚 1.1，**禁用贪心解码**（会陷入重复）。

## 已知局限

- 只训练了「下单 → 写章节」一种能力，问它「这本书讲什么」会退回通用助手口吻
- 2000 字以上偶发人名串位，极少数位置中英混杂
- 单卡 DCU 上约 3 tok/s，2000 字约需 11 分钟
