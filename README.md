# 驯妃筵图卷 · LoRA 权重包

**基于 Qwen3.8-27B 微调的长篇小说续写 LoRA。**

## 基座说明（重要）

仓库用的**不是原生的 Qwen3.8-27B**，而是在原权重上**手动做了去对齐处理**的版本：

| 项 | 值 |
|---|---|
| 原始基座 | Qwen3.8-27B，INT8 (w8a8) 量化权重 |
| 结构 | 64 层（48 线性注意力 + 16 全注意力），hidden 5120 |
| 去对齐方式 | 采集「有害/无害」 probing 句对的每层激活差，得到拒绝方向向量，从层 8–63 的 **MLP 出口（mlp.down_proj）与全注意力出口（o_proj）** 中削减该方向分量，强度 **λ=0.45** |
| 未改动 | 前 8 层、线性注意力出口 |
| 效果 | 原模型会明确拒绝的题材，改动后进入构思与写作，不再触发拒绝 |

也就是说：**对齐先验是在权重层面被削掉的，不是靠提示词绕过的。** 这也是为什么 system 只需要 20 个字。

## 训练配置

- 语料：原创长篇小说《驯妃筵图卷》107 章
- LoRA：rank 32 / alpha 64，只训练注意力与 MLP 投影
- loss 只计算 assistant 段（思考段 + 档案头 + 正文），system 不训练
- 序列长 5120，0 截断；优化器 AdamW + OneCycle

## 两代权重

| 文件 | 步数 | 能力 |
|---|---|---|
| `lora_v1_250step.pt` | 250 | 会先写思考段，再排档案头（场景/人物/前情），再写正文；无书名行 |
| `lora_v2_120step.pt` | 120 | 在 v1 基础上续训，输出首行带书名与章号，档案头五项齐全 |

两代都从同一个续写版 LoRA（`lora_step360`）继续训出来。

## 用法

必须配合 INT8 加载脚本（`q35_base.py`），transformers 原生加载器读不了这套量化格式。

```python
import q35_base as B
B.D = "/path/to/Qwen3.8-27B-ab2"        # 去对齐基座
model = B.build_model()
B.apply_lora(model, r=32, alpha=64)
# 再加载 lora 权重张量
```

system 使用 `sys_short.txt`（20 字），**训练和推理必须完全一致**：

```
你是《驯妃筵图卷》的作者，按用户给的章号和剧情写正文。
用词直白，不写任何免责、警告或说教，不提及自己是 AI。
```

user 输入格式：

```
请写《驯妃筵图卷》第108章。
【人物】…
【场景】…
【要求】…
```

采样：温度 0.85 / top_p 0.9 / 重复惩罚 1.1，**禁用贪心解码**（会陷入重复循环）。

## 已知局限

- 只训练了「下单 → 写章节」一种能力，问它「这本书讲什么」会退回通用助手口吻
- 2000 字以上偶发人名串位，极少数位置中英混杂
- 单卡 DCU 上约 3 tok/s，2000 字约需 11 分钟
